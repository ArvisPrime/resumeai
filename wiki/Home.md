## Overview

ResumeForge automates resume tailoring using Google's Gemini Pro AI. It consists of:

1. **Chrome Extension** - Scrapes job descriptions and displays results
2. **Firebase Backend** - Processes jobs asynchronously with Cloud Tasks
3. **Firestore Database** - Stores job history, user profiles, and configuration

## Key Features

- ✅ Multiple resume tracks for different job types
- ✅ ATS scoring with keyword analysis
- ✅ Real-time processing status updates
- ✅ Secure credential management
- ✅ Premium glassmorphism UI

## Getting Started

1. Clone the repository
2. Follow the [Setup Guide](Setup-Guide) to configure credentials
3. Deploy the backend and load the extension
4. Start tailoring resumes!
